项目名：智演 Agent” 面向城市高密度人群风险治理的 AI 数字孪生推演工作区**  
**项目负责人 / 前端交互与可视化负责人 / AI Agent 推演系统负责人**  
**技术栈：JavaScript、HTML、CSS、Canvas 2D/2.5D 等距渲染、FastAPI、Pydantic、NumPy、LangChain、ChromaDB、LLM、RAG**

- 面向大型活动、交通枢纽等高密度人群场景，设计并实现一套浏览器端 AI 数字孪生推演工作区，将“参数配置、实时沙盘、Agent 认知日志、RAG 诊断报告、干预方案复演”整合为单页交互产品。
- 负责核心前端工作区搭建：使用原生 JavaScript 管理全局运行状态、接口请求、动画帧播放、报告历史、Agent 选中/悬浮/锁定等复杂交互；通过模块化函数拆分数据加载、仿真播放、指标更新、日志渲染和报告弹窗逻辑。
- 自研 Canvas 2.5D 可视化沙盘：基于等距投影将二维人群轨迹映射为具有空间纵深的街区场景，绘制建筑体块、热力网格、风险区域、干预护栏、Agent 光点、选中描边和涟漪反馈，实现接近三维工作区的浏览器内实时渲染体验。
- 构建 AI 能力的可操作界面：将后端多 Agent 推演、慢脑 LLM 认知日志和 RAG 诊断结果转化为前端可理解、可点击、可复演的工作流；支持从报告推荐方案一键进入二次仿真，对比干预前后峰值密度、危险步数和慢脑触发次数。
- 采用深色玻璃拟态与 Bento Dashboard 信息架构，设计视频背景、沉浸式全屏推演、右侧认知流、横向报告历史和响应式布局，使复杂仿真数据具备清晰的产品化展示能力。

成果：中国机器人及人工智能大赛（国奖）
